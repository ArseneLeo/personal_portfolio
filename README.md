Personal Portfolio Website

Welcome to my personal portfolio website! This project showcases my academic background in Software Development, technical skills, web engineering projects, and contact details.

Key Features
- Semantic HTML5:Structured with standard elements (`<header>`, `<nav>`, `<main>`, `<section>`, `<footer>`).
- Modern CSS Architecture:Clean styling using Google Fonts (Inter), custom color palettes, reusable components, and responsive cards.
- Flexbox & Media Queries:Smooth layouts that dynamically adjust across mobile, tablet, and desktop viewports.
- Interactive UI:Smooth transition states and hover effects across all navigation links and primary call-to-action buttons.

Tech Stack
- Structure:HTML5
- Styling:CSS(CSS Variables)
- Deployment:GitHub Pages
